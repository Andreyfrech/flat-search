# Подбор квартиры: север Москвы, до 20 млн ₽

Сравнительная таблица двушек и трёшек в районах Бибирево, Лианозово, Отрадное, Северное и Южное Медведково, Марфино, Северный, Алтуфьевский.

Критерии: от 48 м², кухня от 8 м², не первый и не последний этаж, балкон или лоджия, до метро не больше 15 минут пешком, без долей, апартаментов и пятиэтажек.

Источник: объявления Циана, срез на 04.11.2026. Цены могут измениться — проверяйте по ссылкам.

Страница — один файл `index.html`, открывается в браузере без сборки.
