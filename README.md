# Подбор квартиры: север Москвы

Сервис сам собирает объявления о продаже квартир с Циана каждые 2 дня, отбирает подходящие и показывает их на странице:
**https://andreyfrech.github.io/flat-search/**

На странице:
- вкладки «Лучшие», «Двушки пешком до метро», «Двушки: метро на транспорте», «Трёшки», «Новые и подешевевшие»;
- цена за м² и сравнение с медианой по району;
- отметки «новое», снижение цены, одна и та же квартира у разных агентов;
- список объявлений, пропавших из выдачи (проданы или сняты).

## Как это работает

| Файл | Что делает |
| --- | --- |
| `config.json` | Условия отбора: районы, бюджет, площадь, кухня, этажи, время до метро и т. д. |
| `scraper/update.py` | Скачивает объявления через API Циана, фильтрует, считает медианы, ведёт историю цен. Только стандартная библиотека Python, ничего ставить не нужно. |
| `data/flats.json` | Готовая подборка, её читает страница. |
| `data/history.json` | Когда объявление появилось и как менялась цена. |
| `.github/workflows/update.yml` | Запускает обновление каждые 2 дня в 07:17 по Москве и сохраняет результат в репозиторий. |
| `index.html` | Страница с таблицей. |

## Как поменять условия

Отредактируйте `config.json` прямо на GitHub (значок карандаша) и сохраните. Новые условия применятся при следующем обновлении. Чтобы не ждать, откройте **Actions → Обновление подборки квартир → Run workflow**.

Коды районов Циана: Алтуфьевский 40, Бибирево 42, Лианозово 44, Марфино 46, Отрадное 49, Северный 52, Северное Медведково 53, Южное Медведково 54.

## Запуск на своём компьютере

```
python scraper/update.py
```

Нужен Python 3.9+. Результат появится в `data/`.
