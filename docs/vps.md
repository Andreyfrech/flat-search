# Сбор данных с сервера в России

Циан показывает капчу запросам с зарубежных серверов, в том числе с серверов GitHub. Поэтому сам сбор запускается на небольшом арендованном сервере (VPS) в России, а GitHub по-прежнему хранит код, расписание и страницу.

Сервер работает круглосуточно, ваш компьютер для этого не нужен.

## 1. Арендовать сервер

Подойдёт самый дешёвый тариф любого российского хостинга (Timeweb Cloud, Selectel, REG.RU, Beget и т. п.):
- система **Ubuntu 22.04 или 24.04**;
- 1 ядро, 1 ГБ памяти, 10 ГБ диска — этого с запасом;
- лучше тариф с посуточной оплатой: если Циан заблокирует и этот сервер, можно сразу удалить его, не заплатив за месяц.

После создания хостинг покажет IP-адрес и пароль пользователя `root`.

## 2. Проверить, что Циан отвечает этому серверу

Подключитесь к серверу (в Windows: откройте «Терминал» или PowerShell):

```
ssh root@IP-АДРЕС-СЕРВЕРА
```

и выполните:

```
git clone https://github.com/Andreyfrech/flat-search
cd flat-search
python3 scraper/update.py
```

Если в конце написано «Готово: получено …» — всё работает, идите дальше. Если «Циан показал капчу» — этот хостинг тоже заблокирован, попробуйте другого провайдера.

## 3. Подключить сервер к GitHub как «раннер»

1. Откройте https://github.com/Andreyfrech/flat-search/settings/actions/runners/new
2. Выберите **Linux**, архитектура **x64**.
3. GitHub покажет блок команд **Download** и **Configure**. Выполните их по очереди на сервере. Перед этим создайте отдельного пользователя — запускать раннер от `root` GitHub не даёт:

```
adduser --disabled-password --gecos "" runner
su - runner
```

   Затем вставьте команды со страницы GitHub. На все вопросы `config.sh` можно просто нажимать Enter.
4. Сделайте так, чтобы раннер запускался сам после перезагрузки сервера:

```
exit
cd /home/runner/actions-runner
./svc.sh install runner
./svc.sh start
```

На странице https://github.com/Andreyfrech/flat-search/settings/actions/runners раннер должен появиться со статусом **Idle**.

## 4. Переключить обновление на свой сервер

1. Откройте https://github.com/Andreyfrech/flat-search/settings/variables/actions/new
2. Name: `RUNNER`, Value: `self-hosted`, нажмите **Add variable**.
3. Откройте **Actions → Обновление подборки квартир → Run workflow**, чтобы не ждать расписания.

Через пару минут на странице https://andreyfrech.github.io/flat-search/ появятся данные. Дальше обновление идёт само каждые 2 дня.
